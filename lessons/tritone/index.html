写歌用的和弦

C

三全音代替用 bII7 换掉 V7。C 调里用 Db7 换 G7。两颗属七共用一组三全音：B 和 F。低音改成半音下行，Db 走到 C。

级数

在 C 调里放在几级

bII7 换掉 V7。C 调里用 Db7 代替 G 或 G7，低音 Db 走到 C。它和 G7 共用 B 和 F 这一组三全音。

C 调实用地图 · 常用进行的替换

    点任意按钮或琴键，浏览器才会出声。

    01

    钢琴

    先弹 G7，再弹 Db7，听三音和降七对调了位置，低音差了个减五度。然后听 Db7 走到 C。

    bII7 半音下行到 I。它也可以先接在 ii 后面：ii、bII7、I。

    02

    吉他

    把位就是一颗普通属七，根音在主音上面半音。升十一那一把是可选的亮色，三全音代替经常顺手带上它。

    指板是演奏视角：低头看琴时，低音弦在下、靠近你，高音弦在上。圆点相对的是代替和弦自己的根音。C 调的 Db7：F 是三音，B 是降七。这两颗音也在 G7 里。 闷住的弦不标音级。圆点不是手指序号。转调之后音级不变。

    03

    贝斯

    贝斯弹 Db，解决到 C。半音要听得见。

    04

    今天练

    当前调弹 V7 和 bII7，再都解决到 I。说出哪两个音没变。

    05

    用到歌里

    先听它在歌里干什么，再仿两三格和弦，最后放进自己的进行。没有歌词。点下去先是柱式和弦，再把同一段用琶音走一遍，大约每分钟 90 拍。每格通常是一小节。这段按写下的调，不跟上面选的调走。

    爵士 / 功能

    Just the Two of Us 的间奏

    降半音解决的那一下

    听间奏里 Dbmaj7 接到 C7，C7 再落到 Bmaj7。C7 没有按五度上行解决，而是半音下行。这就是三全音代替的走法：属七当成上一条和弦的降二级。主歌不是这条。

    仿只留这一下半音解决。

    原调那一截

    C7 · Bmaj7

    同样的关系，落在 C

    D♭7 · Cmaj7

    依据：Spy Tunes 和 Tab4U 都把间奏写成 Dbmaj7、C7、然后 Bmaj7。三全音代替是对这个半音下行的叫法。

    用

    ii 后面换一条属

    用同一句的结尾，属七用原来的 G7，或换成 Db7。再听一句带 ii 的。选更顺的那条，不必两条都留。

    原来的 V

    Dm7 · G7 · Cmaj7

    换成 bII7

    Dm7 · D♭7 · Cmaj7

    只听半音低音
