# 色彩和弦

给写歌的人用的色彩和弦百科。写粤语歌、普通话歌的伴奏，不是爵士教材。吉他、贝斯和键盘放在同一页里听。

这一版写成了第一课 **add9**（从 Cadd9 听起）：

- 钢琴齐奏、琶音上行、琶音下行，也可以点单键
- 吉他是不靠空弦的移动把位，可以整把换调
- 全指板能看到这些把位落在哪，也可以一张一张听
- 贝斯守根音，或加上五音
- 十二个调一起转。圆点里是音级 R、3、5、9，转调之后也不改成手指序号
- A 弦根音那把（C 调是 x-3-5-5-3-3）没有三音，圆点只有 R、5、9

后面的题目先排在目录里，模拟器还没做：下一课是 6 / 6/9，然后是大七与大九、小七与小九、挂留和附加、斜杠和弦。再往后是副属、经过减和弦、调式互换。更后面是属九与属十三、变化音、三全音代替、ii–V–I 的色彩。

## 本地打开

仓库里都是静态文件，用相对路径，不需要服务器也能听。Chrome、Edge、Firefox、Safari 都可以。

1. 双击根目录的 `index.html`，从目录进入第一课。也可以直接打开 `lessons/add9/index.html`。
2. 点「齐奏」或琴键。浏览器要等你先点一下，才会出声。

如果浏览器拦住了本地文件里的脚本，在仓库根目录开一个静态服务器：

```bash
python3 -m http.server 8741
```

然后打开 [http://127.0.0.1:8741](http://127.0.0.1:8741)。

校对第一课的品位、音级和音色：

```bash
node lessons/add9/verify.js
```

## 线上

公开页面还没打开。把代码推进 `main` 可以，但这个权限改不了 Pages（GitHub 返回需要 `pages=write`）。所以现在没有可以打开的公开地址。

请在浏览器里点这几下：

1. 打开 [Settings → Pages](https://github.com/littlekok852/JazzyChords/settings/pages)。
2. 在 **Build and deployment** 里，Source 选 **Deploy from a branch**。
3. Branch 选 **main**，文件夹选 **/ (root)**。
4. 点 **Save**。

保存之后，同一页上方会出现 **Visit site**。那条链接才是公开地址。第一次发布常常要等一两分钟，刷新这一页就能看到。站点用的是 `main` 根目录的 `index.html`，不用再加 Actions 工作流。

如果保存后构建失败，用这个账号再往 `main` 推一次。GitHub 有时要管理员、并且邮箱已验证的人推过发布分支，页面才会出来。
