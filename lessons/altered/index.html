色彩百科 第十一课 · 变化属和弦

写歌用的和弦

C

变化属和弦仍是属七，只是九音、五音或十一音被升高或降低。降九更挤，升九更冲，升十一更亮，降十三更暗。主歌里的流行歌不必用它。它是紧张的 V，可有可无。

级数

在 C 调里放在几级

变化音仍是 C 调的 V：G7 加上降九、升九、升十一或降十三，去 C 或 Am。a 小调如果要用更紧的属七，点最后的 E7b9，那不是默认。

C 调实用地图 · 常用进行的替换

    点任意按钮或琴键，浏览器才会出声。

    01

    钢琴

    每一种都留着三音和降七。变化的是另外一个音。四个钮分开听，不要一次叠四种。

    变化属七仍然去主和弦，去大调或小调都可以。变化音在解决的那一拍离开。

    02

    吉他

    把位都在属音的低把位，跨度两三品。升九那把就是常被叫做 Hendrix 和弦的指法，这里只学这个音，不学整首歌。

    指板是演奏视角：低头看琴时，低音弦在下、靠近你，高音弦在上。b9、#9、#11、b13 都是相对这颗属七的根音。三音仍写 3，降七仍写 b7。 闷住的弦不标音级。圆点不是手指序号。转调之后音级不变。

    03

    贝斯

    贝斯守属音。变化音放在上面。

    04

    今天练

    只练一种：G7 和 G7b9 都去 C。听 Ab 有没有让属七更紧。

    05

    用到歌里

    先听它在歌里干什么，再仿两三格和弦，最后放进自己的进行。没有歌词。点下去是钢琴齐奏，每格一拍，连放两遍。这段按写下的调，不跟上面选的调走。

    爵士 / 功能

    Isn't She Lovely 里的一格

    Stevie Wonder · 原调 E · 副歌前

    听副歌前除了 Amaj7，下一格是 G#7#5。升五和降十三是同一个音高。这是变化属和弦，不是大七。

    仿两格：大七，然后这颗变化属七。

    原调 E

    Amaj7 · G♯7#5

    转到 C

    Fmaj7 · E7#5

    依据：Spy Tunes；Jon MacLennan。两处都把这一格写成 G#7#5。

    用

    可有可无的紧张

    用流行歌可以永远不用。如果一句的属七太干，只换一种变化再解决。听完选一种，或者换回去。

    Dm7 · G7 · C

    降九

    升九

    Dm7 · G7#9 · C

    Dm7 · G7b13 · Cm
