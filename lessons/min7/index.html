色彩百科 第四课 · 小七 / 小九

写歌用的和弦

C

在 C 大调里，小七不放在 C 上。默认是 ii 的 Dm7，然后是 vi 的 Am7，再是 iii 的 Em7。a 小调里先用 Am7 当主和弦。Cm7 只是借来的小主和弦，放在最后，不是默认。

级数

在 C 调里放在几级

小七不要默认成 Cm7。C 调里先是 ii 的 Dm7，然后 vi 的 Am7、iii 的 Em7。借来的 i 才是 Cm7，放在最后。a 小调里先用 Am7。

    01

    钢琴

    左手是这一级自己的根音：D、A 或 E，不是 C。右手听降三和降七。小九只在同一级上加九音。

    Dm7 去 G。Am7 可以停着，也可以去 Dm 或 F。Em7 常去 Am。Cm7 是借来的，解决回 C 或接到 Fm。

    02

    吉他

    圆点上的 R 是这一级的根音。Dm7 的 R 是 D，Am7 的 R 是 A。不要把它们读成 C 和弦。

    指板是演奏视角：低头看琴时，低音弦在下、靠近你，高音弦在上。R、b3、5、b7、9。b3 比大三低半音，b7 比大七低半音。 闷住的弦不标音级。圆点不是手指序号。转调之后音级不变。

    03

    贝斯

    贝斯守根音或五音。降七先留在上面。

    04

    今天练

    在 C 调把 Dm7、Am7、Em7 各弹一次，再说它们要去哪。最后才点「借来的 i」。

    05

    用到歌里

    先听它在歌里干什么，再仿两三格和弦，最后放进自己的进行。没有歌词。点下去先是柱式和弦，再把同一段用琶音走一遍，大约每分钟 90 拍。每格通常是一小节。这段按写下的调，不跟上面选的调走。

    流行

    Just the Two of Us 里的小七

    同一首歌的旁边

    听上一课的 Dbmaj7 旁边就是 Fm7，还有 Ebm7。谱上写的是小七，不是小九，这里不升级。

    Miles Davis · 调式 · 不是 ii–V
