# 色彩和弦

给写歌的人用的色彩和弦百科。写粤语歌、普通话歌的伴奏，不是爵士教材。吉他、贝斯和键盘放在同一页里听。

第一遍十三课都写成了，从 add9 到 ii–V–I。每课一个颜色，指板是演奏视角，圆点是音级。例子在 C 调里，放在这个颜色真正好用的级数上。

写歌时可以先看两页：`map/` 是 C 调实用地图，`swap/` 是常用进行的替换（1645、卡农、4536251）。

**add9**（从 Cadd9 听起）：

- 钢琴齐奏、琶音上行、琶音下行，也可以点单键
- 吉他是不靠空弦的移动把位，可以整把换调
- 全指板能看到这些把位落在哪，也可以一张一张听
- 贝斯守根音，或加上五音
- 十二个调一起转。圆点里是音级 R、3、5、9，转调之后也不改成手指序号
- A 弦根音那把（C 调是 x-3-5-5-3-3）没有三音，圆点只有 R、5、9

**6 和 6/9**（从 C6、C6/9 听起）：

- 没有七音。6 比大七更稳，6/9 是大调五声音阶那五个音
- 钢琴可以对照大三、6、6/9 和大七。大七只作对照，没有做成一把吉他课
- 吉他仍是不靠空弦的移动把位。圆点是 R、3、5、6、9
- 6 的圆点里没有 9。贝斯守根音，不把六音放在低音上

每一课都有「用到歌里」：先听、再仿两三格和弦、再换进自己的进行。没有歌词，也没有整首歌的谱。

顺序是：add9，6 / 6/9，大七 / 大九，小七 / 小九，挂留和附加，斜杠和弦，副属，经过减，调式互换，属九 / 属十三，变化音，三全音代替，ii–V–I。

## 本地打开

仓库里都是静态文件，用相对路径，不需要服务器也能听。Chrome、Edge、Firefox、Safari 都可以。

1. 双击根目录的 `index.html`，从目录进入课程。也可以直接打开 `lessons/add9/index.html` 或 `lessons/six/index.html`。
2. 点「齐奏」或琴键。浏览器要等你先点一下，才会出声。

如果浏览器拦住了本地文件里的脚本，在仓库根目录开一个静态服务器：

```bash
python3 -m http.server 8741
```

然后打开 [http://127.0.0.1:8741](http://127.0.0.1:8741)。

校对品位、音级和音色：

```bash
node lessons/add9/verify.js
node lessons/six/verify.js
node lessons/maj7/verify.js
```

## 目录

| 路径 | 状态 |
| --- | --- |
| `index.html` | 目录，学习路径 |
| `map/` | C 调实用地图 |
| `swap/` | 常用进行的替换 |
| `modes/` | 教会调式。大调色彩主音 C，小调色彩主音 A |
| `lessons/add9/` | add9 |
| `lessons/six/` | 6 / 6/9 |
| `lessons/maj7/` | 大七 / 大九 |
| `lessons/min7/` | 小七 / 小九 |
| `lessons/sus/` | 挂留和附加 |
| `lessons/slash/` | 斜杠和弦 |
| `lessons/secondary/` | 副属 |
| `lessons/dim/` | 经过减 |
| `lessons/borrow/` | 调式互换 |
| `lessons/dom9/` | 属九 / 属十三 |
| `lessons/altered/` | 变化音 |
| `lessons/tritone/` | 三全音代替 |
| `lessons/twfive/` | ii–V–I |
| `assets/lesson.js` | 第三课起共用的指板和播放 |
| `assets/voice.js` | 仿奏那几格和弦的音 |

新的课以后放在 `lessons/` 下面，并在首页路径里接上。不要把还没做的课写成空的模拟器页。
