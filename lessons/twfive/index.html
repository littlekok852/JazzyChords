色彩百科 第十三课 · ii–V–I

写歌用的和弦

C

ii–V–I 是把前面学过的颜色按一条拉力排好：小七去属七，属七去主和弦。这一课不发明新和弦，只把已经会的小七、属七、大七，以及小九、属十三、6/9 装进这一句。

级数

在 C 调里放在几级

就在 C 调：Dm7、G7、Cmaj7。加色是 Dm9、G13、C6/9。不要改成别的调里、根音却是 C 的 ii–V–I。

C 调实用地图 · 常用进行的替换

    点任意按钮或琴键，浏览器才会出声。

    01

    钢琴

    先听朴素的三格，再听加了颜色的三格。钮可以单独听 ii、V、I。

    拉力在 V 到 I。ii 只是把 V 介绍出来。主和弦用大七更悬，用 6/9 更稳。

    02

    吉他

    每一钮是这一句里的一颗和弦，把位都是前面课里的移动形。转调之后，ii、V、I 一起搬。

    指板是演奏视角：低头看琴时，低音弦在下、靠近你，高音弦在上。小七看 b3 和 b7，属七看 3 和 b7，大七看 7，6/9 看 6 和 9。不要在一颗和弦上读到它没有的音。 闷住的弦不标音级。圆点不是手指序号。转调之后音级不变。

    03

    贝斯

    低音就走 ii 的根音、V 的根音、I 的根音。颜色放在上面。

    04

    今天练

    当前调弹两遍：先 Dm7、G7、Cmaj7，再 Dm9、G13、C6/9。留下更适合你这首歌的那一遍。

    05

    用到歌里

    先听它在歌里干什么，再仿两三格和弦，最后放进自己的进行。没有歌词。点下去先是柱式和弦，再把同一段用琶音走一遍，大约每分钟 90 拍。每格通常是一小节。这段按写下的调，不跟上面选的调走。

    爵士 / 功能

    Autumn Leaves 的开头

    标准曲 · 只取 ii–V–I

    听秋叶开头在 B♭ 调：Cm7、F7、Bbmaj7。这就是 ii–V–I。这里只取这三格，不排整首。

    仿三格，再挪到 C。

    原调 B♭

    Cm7 · F7 · B♭maj7

    转到 C

    Dm7 · G7 · Cmaj7

    这是标准曲开头最常见的三格。后面还有小调的 ii–V，这一课不展开。

    流行

    流行里的朴素收法

    不是爵士进行

    听很多歌只是小三、大三的属、主和弦，没有七音。它和爵士 ii–V–I 是同一条低音，颜色少很多。

    仿三格，故意不加七音。

    C 调

    Dm · G · C

    这一组和上面的爵士分开。

    用

    两种颜色，选一种

    用同一句低音，朴素的一套，和用了小九、属十三、6/9 的一套。写粤语歌或国语歌时留更贴的那套，不必上满。

    Dm · G · C
