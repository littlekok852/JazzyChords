色彩百科 第六课 · 斜杠和弦

写歌用的和弦

C

斜杠和弦的低音不是根音。低音可以是和弦里的三音或五音，也可以是从旁边走过去的音。上面的和弦先别大改，让低音自己走。

级数

在 C 调里放在几级

斜杠在这里是低音线，不是一串 C 根音。先听 C、G/B、Am、Am/G，低音是 C、B、A、G。再听 C、C/E、F、G，低音走到三音。

C 调实用地图 · 常用进行的替换

    点任意按钮或琴键，浏览器才会出声。

    01

    钢琴

    左手专门弹斜杠后面的那个音。右手仍是原来的三和弦。点不同的钮，听低音在换、上面不怎么换。

    低音顺级走的时候，上面可以留在同一个和弦，也可以换成低音所属的那个三和弦。

    02

    吉他

    圆点上，最低的那个音就是斜杠后面的音。把它和根音分开看。空弦的 C/E、Am/G 只作对照。

    指板是演奏视角：低头看琴时，低音弦在下、靠近你，高音弦在上。R 仍是和弦根音，不是低音。低音如果是三音，圆点写 3。低音如果在和弦外面，按它离根音的度数写，比如 Am/G 的 G 是 b7。 闷住的弦不标音级。圆点不是手指序号。转调之后音级不变。

    03

    贝斯

    这一课贝斯就是斜杠。先弹低音，再弹和弦根音，听两个不是同一个音。

    04

    今天练

    在 C 调把 C、G/B、Am、Am/G 连起来，只唱低音：C、B、A、G。

    05

    用到歌里

    先听它在歌里干什么，再仿两三格和弦，最后放进自己的进行。没有歌词。点下去是钢琴齐奏，每格一拍，连放两遍。这段按写下的调，不跟上面选的调走。

    流行

    晴天

    周杰伦 · 常见吉他编配 · 原调 G

    常见吉他编配，未对原编逐音核对。

    听第一课已经用过这圈。这里单看 D/F#：低音是 F#，和弦还是 D。转到 C 之后是 G/B，低音是 B。

    仿四格。低音在主歌里往下走了一步。

    原调 G

    Em7 · Cadd9 · G · D/F♯

    转到 C

    Am7 · Fadd9 · C · G/B

    依据和第一课相同：Passionet、Chord4、Chordy 的吉他谱。常见吉他编配，不是逐音对过原编。

    用

    低音走下来

    用没有再核对到一首和这四格完全一致、又足够清楚的流行谱，所以这一条当你自己的低音练习。低音是 C、B、A、G。再单独听三音在低音的 C/E。

    顺级低音

    C · G/B · Am · Am/G

    三音当低音

    C · C/E · F · G
