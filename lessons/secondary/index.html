色彩百科 第七课 · 副属

写歌用的和弦

C

副属是临时把旁边的和弦当成主和弦，先弹它的属七。C 调里默认先听 D7，它是 V/V，去 G。E7 是 V/vi，也是 a 小调的属七。A7 去 Dm。C7 是 V/IV，去 F，不要把它当成「那个」副属的统称，更不要当成主和弦上的色彩。

级数

在 C 调里放在几级

默认是 D7，V/V，去 G。E7 是 V/vi，去 Am，也是 a 小调的属七。A7 是 V/ii，去 Dm。C7 是 V/IV，去 F。C7 不是主和弦的色彩。

C 调实用地图 · 常用进行的替换

    点任意按钮或琴键，浏览器才会出声。

    01

    钢琴

    先听属七自己的三音和降七，再听它解决到的那个和弦。钮上写的是功能：V/V、V/ii、V/vi、V/IV。

    副属要去它自己的临时主和弦：D7 去 G，E7 去 Am，A7 去 Dm，C7 去 F。不去，就变成别的颜色。

    02

    吉他

    把位是普通的属七。C 调里 V/V 的根音是 D，V/ii 是 A，V/vi 是 E，V/IV 是 C。

    指板是演奏视角：低头看琴时，低音弦在下、靠近你，高音弦在上。圆点相对的是这颗属七自己的根音：R、3、5、b7。不要把它们读成主调的音级。 闷住的弦不标音级。圆点不是手指序号。转调之后音级不变。

    低把位

    高把位

    03

    贝斯

    贝斯给这颗属七的根音，解决的时候再跳到下一条的根音。

    04

    今天练

    在 C 调弹 D7 到 G，E7 到 Am，A7 到 Dm，C7 到 F。每对只听有没有被拉过去。

    05

    用到歌里

    先听它在歌里干什么，再仿两三格和弦，最后放进自己的进行。没有歌词。点下去先是柱式和弦，再把同一段用琶音走一遍，大约每分钟 90 拍。每格通常是一小节。这段按写下的调，不跟上面选的调走。

    爵士 / 功能

    Don't Know Why

    Norah Jones · 原调 B♭ · 功能和弦

    听Ethan Hein 把主歌写成一串副属：Bbmaj7 接 Bb7，Bb7 是去 Eb 的属七；后面 Gm7 接 C7，C7 是去 F 的属七。D 那一格有的谱写 D7，有的写 D(#5)，这里不写进仿奏。

    仿只仿大家一致的两小段。

    原调 B♭

    B♭maj7 · B♭7 · E♭maj7

    原调后半

    Gm7 · C7 · F7

    前半挪到 C

    Cmaj7 · C7 · Fmaj7

    后半挪到 C

    Am7 · D7 · G7

    依据：Ethan Hein；Spy Tunes。Bb7 和 C7 的走向两处一致。D 和弦的写法不一致，所以不放进仿奏。

    流行

    Yesterday

    The Beatles · 原调 F

    听落到 Dm 之前是 A7。Dm 是 F 调的 vi，A7 就是 vi 的属七。A7 前面那一格，有人写 Em7，有人写 Em7b5，这里不把那一格写死。

    仿只留属七和它去的小和弦。

    原调 F

    A7 · Dm

    转到 C

    E7 · Am

    依据：College Music Symposium 对 Yesterday 的和声说明；一份 F 调和弦谱把 A7 放在 Dm 前面。

    用

    给进行加一股拉力

    用原来的 C、Am、F、G 很平。把 Am 前面换成 A7，或者在 G 前面加 D7。听多出来的那一下有没有把下一条和弦拉过来。
