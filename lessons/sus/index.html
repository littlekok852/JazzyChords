色彩百科 第五课 · 挂留和附加

写歌用的和弦

C

在 C 调里，挂留最有用的是 V：Gsus4 再落到 G。四音悬着，三音不在，所以想解决。add9 是另一件事：三音留着再加九音，常用在 I 和 IV，不在这一课的默认钮上。

级数

在 C 调里放在几级

挂留放在 V：默认是 Gsus4，再点「落到 V」听 G。sus2 仍是这一级。对照的 add9 是 IV 的 Fadd9，三音还在，不是挂留。

C 调实用地图 · 常用进行的替换

    点任意按钮或琴键，浏览器才会出声。

    01

    钢琴

    默认响的是 Gsus4。点「落到 G」听三音回来。sus2 是同一级把四音换成二音。对照钮里的 add9 是 Fadd9，三音还在。

    sus4 最常回到大三，四音落到三音。sus2 可以回去，也可以就停着。add9 不必解决。

    02

    吉他

    第一课 A 弦那把 add9（x-3-5-5-3-3）没有三音，响出来就是 sus2。这一课把那把放在 sus2 里。三音还在的 add9 用高把位那两把。空弦的 Cadd9、Dsus4 只作对照。

    指板是演奏视角：低头看琴时，低音弦在下、靠近你，高音弦在上。sus2 是 R、2、5。sus4 是 R、4、5。add9 是 R、3、5、9。2 和 9 同音高：2 表示三音被换掉，9 表示三音还在。 闷住的弦不标音级。圆点不是手指序号。转调之后音级不变。

    03

    贝斯

    贝斯给根音。挂留的紧张在上面的 2 或 4。

    04

    今天练

    同一个根音，依次弹大三、sus4、sus2、add9。说出三音还在不在。

    05

    用到歌里

    先听它在歌里干什么，再仿两三格和弦，最后放进自己的进行。没有歌词。点下去是钢琴齐奏，每格一拍，连放两遍。这段按写下的调，不跟上面选的调走。

    流行

    Wonderwall

    Oasis · 常见吉他编配 · 变调夹 2 品

    常见吉他编配，不是逐音对过原编。变调夹在第 2 品。G 这里按大三，不把整首说成 add9。

    听主歌循环是 Em7、G、Dsus4、A7sus4，空的是 sus4。副歌前才出现 Cadd9，旁边仍是 Dsus4。挂留和附加在同一首歌里，干的不是一件事。

    仿先四格主歌，再三格副歌前。

    谱面调

    Em7 · G · Dsus4 · A7sus4

    挪到以 C 为主音的一圈

    Am7 · C · Gsus4 · D7sus4

    副歌前，谱面调

    Cadd9 · Dsus4 · Em7

    副歌前，挪到 C

    Fadd9 · Gsus4 · Am7

    依据：Acoustic Binder；Heartwood Guitar；Open Guitar Chords。主歌和弦和副歌前的 Cadd9、Dsus4 三处一致。

    Message in a Bottle

    The Police · 前奏和主歌

    听四格里三格是 sus2：C#sus2、Asus2、Bsus2。最后一格常被说成 sus2，可是里面有降三，应记成 F#madd9。就差这个三音。

    仿四格。最后一格按有三音的小调附加来记。

    原调

    C♯sus2 · Asus2 · Bsus2 · F♯madd9

    第一格挪成 Csus2

    Csus2 · A♭sus2 · B♭sus2 · Fmadd9

    依据：Spy Tunes；GuitarTuna。Spy Tunes 写明最后一格是 F#madd9。

    用

    同一个低音，三音在不在

    用低音都从 C 走。大三有 E，sus4 把 E 换成 F，add9 是 E 还在再加 D。再用你自己的四格换一次。
